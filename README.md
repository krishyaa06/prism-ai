# ◇ Prism AI

> Build. Explore. Create.

Prism AI is a beautiful, developer-first workspace for organizing ideas,
documents, research and AI-assisted workflows.

## Preview

The project includes a polished animated landing page with:

- Modern dark developer aesthetic
- Responsive layout
- Prism AI branding
- Animated hero section
- Workspace dashboard preview
- Feature cards with hover animations
- Mobile-friendly design
- Reduced-motion accessibility support

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Webpack-compatible development setup

## Getting Started

### Prerequisites

- Node.js 20+
- npm
- Git

### Installation

```bash
git clone [https://github.com/krishyaa06/prism-ai.git](https://github.com/krishyaa06/prism-ai.git)
