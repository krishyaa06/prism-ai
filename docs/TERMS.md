## 2. Eligibility and authority

Use Prism only if you are legally able to agree to applicable terms in your

## 3. What the service does

Prism can route a prompt and screen context to either an on-device model or an
operator-configured cloud model. The model may produce inaccurate, incomplete,
or unsafe plans. The Android app uses operating-system permissions and local
tools to execute supported actions. Android security restrictions remain in
force; Prism does not promise A-to-Z access or task completion.

## 4. User control and authorization

Review the task plan before approving it. Your approval may authorize multiple
follow-up actions in that task, including actions that modify data. Stop the
agent if it leaves the approved task. Review destinations and results. Android
may display additional confirmations. Never rely on model instructions alone
for a payment, purchase, message, post, deletion, account change, or other
material action.

You authorize Prism to transmit task data to the model endpoint you configure
only when you select cloud mode and confirm the task. You may instead select
local inference. Persistent memory is optional and should be used only when
you opt in for that task.

## 5. Acceptable use

Do not use Prism to violate laws, access someone else's device or account,
evade security controls, stalk or surveil people without authorization, send
spam, commit fraud, interfere with emergency services, or process data without
the necessary rights and consent. Do not use it as the sole decision-maker in
medical, legal, employment, credit, housing, financial, or safety-critical
contexts.

## 6. Accounts, tokens, and connectors

Keep passwords and API tokens confidential. Revoke a token immediately if it
is exposed. You are responsible for actions initiated with your account or
tokens, except where applicable law provides otherwise. Connect only services
and MCP servers you trust, and grant the least privilege needed. Third-party
services have their own terms and privacy policies.
